# שער A — בדיקת Windows ארוזה

מסמך תוצאות. כל הרצה נרשמת כאן עם גרסאות, חומרה, זמנים וצילומי מסך.
הקריטריון: **התוסף הארוז** פועל. בדיקה מ־localhost לבדה אינה מספיקה.

מקור השער: [../../docs/word-plugin-implementation-plan.md](../../docs/word-plugin-implementation-plan.md) §6.3.

---

## מצב: חסום — לא הורץ

השער לא הורץ, ולא בגלל חוסר זמן: הוא **אינו יכול לעבור** במצב הנוכחי של
אוצריא. הסיבה נמדדה במלואה ומתועדת ב־[spike.md](spike.md) §3, ובקצרה:

תוסף ארוז נטען מ־`file://`, שם ה־origin opaque. מנוע ה־DOCX יוצר module worker,
ו־module worker אינו נטען שם — לא מ־blob (נכשל) ולא מ־data (עובד אך חסום סביב
2MB, וה־worker של המסמך הוא 4.67MB). מ־origin http אותה אריזה בדיוק עובדת,
ו־`onReady` חוזר תוך 470ms.

**תנאי מוקדם לפתיחת השער:** אוצריא מגישה את תיקיית ההתקנה של התוסף מ־
`http://127.0.0.1` וטוענת את ה־entrypoint משם. עד אז אין טעם להריץ את
הצ'קליסט שלהלן — הוא ייכשל בשורה הראשונה.

## מה כן אפשר להריץ עכשיו

טעינה מ־localhost נותנת origin תקין, ולכן מאפשרת לאמת את כל השאר על Windows
ולהפריד כשל מנוע מכשל origin:

- [ ] `npm run dev` במכונת Windows.
- [ ] באוצריא: פאנל התוספים → „טעינה מ־localhost” → `http://localhost:5173`.
- [ ] פתיחת מסמך עברי קטן דרך „פתיחת קובץ Word”.
- [ ] בדיקה חזותית: RTL, ניקוד, טעמים, גופנים.
- [ ] „מודגש” ו„כיוון מימין לשמאל” משנים את המסמך; מצב הכפתור מתעדכן עם הסמן.
- [ ] „ייצוא ל־Word” מוריד קובץ שנפתח ב־Microsoft Word.
- [ ] מסמך של 50 עמודים: זמן פתיחה, גלילה, זיכרון.
- [ ] console נקי מ־errors; אין בקשת רשת יוצאת (Network tab).

תוצאות ההרצה הזאת נרשמות כאן, כולל גרסת אוצריא, גרסת WebView2, חומרה וזמנים.

## הצ'קליסט של השער עצמו — לאחר שהתנאי המוקדם ייסגר

- [ ] `npm run build` ואריזה: `otzaria pack-plugin v2/dist --output otzaria-word-editor-v2.otzplugin --force`.
- [ ] הוולידטור עובר, כולל ולידציית העיצוב על ה־CSS.
- [ ] התקנה ב־Windows בגרסת אוצריא שתומכת בהגשת התוסף מ־origin.
- [ ] `manifest.json` — `minAppVersion` עודכן לגרסה הראשונה שכוללת את השינוי.
- [ ] פתיחת מסמך עברי קטן ומסמך של 50 עמודים מן התוסף **הארוז**.
- [ ] document worker ו־review-index worker נטענים, בלי רשת.
- [ ] עריכת מילה, „מודגש”, RTL, ייצוא, ופתיחת התוצר ב־Word.
- [ ] אותה בדיקה מ־localhost, כדי להפריד כשל מנוע מכשל טעינה.
- [ ] רישום: גרסאות, חומרה, זמן boot, זמן פתיחת 50 עמודים, peak memory, גודל
  `.otzplugin`, console errors, צילומי מסך.
