# ניהול סגנונות במסמך החי

הגלריה מאפשרת שינוי, יצירה מהבחירה, עדכון כך שיתאים לבחירה ושינוי שם לסגנון מותאם. אפשר להצמיד קיצור מקשים לסגנון. מחיקה אינה מוצעת: ממשק אימוץ התבנית של המנוע שומר סגנונות קיימים, ואין מסלול ציבורי שמוחק אותם בלי להחליף את המסמך.

`applyStyleEdit` קוראת גיליון טרי ומעבירה רק הגדרות סגנון שהשתנו דרך `templates.apply` של SuperDoc 2.20. המקור הוא חבילת OPC בת חמישה חלקים: גיליון הגדרות, גוף ריק והקשרים הנדרשים. היא אינה מכילה docDefaults, latentStyles, הגדרות דף, כותרות, ערכת נושא או תוכן מהצילום. המסמך אינו נפתח מחדש, והיסטוריית Undo/Redo נשמרת.

ה-`expectedRevision` מגיע מקריאת המצב שלפני הייצוא ונבדק במנוע גם בשלב הכתיבה. עריכה מקבילה גורמת לסירוב במקום לדריסת שינוי חדש. החלפת טאב לפני תחילת ההחלה מבטלת את הפעולה. החלה שכבר נשלחה נשארת קשורה למופע ול-session המקוריים. דיאלוג נסגר בעת החלפת מסמך. session עם עריכת סגנון פעילה אינו נרדם, נסגר או מוחלף עד סיום הפעולה.

מודגש ונטוי בסגנונות מפוענחים כ-toggle לפי §17.7.3, עם ירושה עצמאית לרכיבי Latin ו-complex script. כתיבה של הערך האפקטיבי הרצוי מייצרת את ה-toggle הנכון יחסית לבסיס.

המנוע הנוכחי אינו מפענח נכון חלק מצירופי toggle בירושת סגנונות. לפני כל החלה נבדקים הסגנונות שהשתנו וגם צאצאיהם. שינוי שיוצר אי-התאמה חדשה בין Word לתצוגה נדחה לפני כתיבה, עם בקשה לבחור בסיס אחר. שינויי גודל, גופן, יישור, רמת חלוקה וסגנונות פשוטים נשארים זמינים.

יישור פסקה מפוענח לפי bidi האפקטיבי דרך docDefaults ושרשרת basedOn, כולל ביטול מפורש של bidi בסגנון LTR.

אימות ממוקד:

- `npm exec vitest run tests/unit/live-style-edit.test.ts tests/unit/style-edit-lifecycle.test.ts tests/unit/docx-style-edit.test.ts tests/component/style-manager.test.ts`
- `npm run build`
- `node scripts/qa/live-style-history-qa.mjs`: מנוע 2.20 אמיתי בדפדפן; Undo/Redo של טקסט ושל סגנונות באותו מופע, סגנונות מותאמים ומובנים שאינם בשימוש, ברירות מחדל וחלקים אחרים נשמרים, ו-revision ישן נדחה.
- `node scripts/qa/style-manager-smoke-qa.mjs`: שינוי, יצירה ושינוי שם דרך הגלריה והדיאלוג, תצוגה ו-DOCX.

- `node scripts/qa/style-toggle-guard-qa.mjs`: סירוב לפני כתיבה במנוע האמיתי, ללא שינוי בתוכן, בקטלוג, בגרסה או בהיסטוריה.
