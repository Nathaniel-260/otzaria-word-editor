# וורד לאוצריא

תוסף לתוכנת [אוצריא](https://github.com/Sivan22/otzaria) שמוסיף לה עורך מסמכים בסגנון Word, לכתיבת חידושי תורה בלי לצאת מהתוכנה. הטקסט הנכתב יושב לצד הספרייה, וכל מקור שמעיינים בו נכנס למסמך בלחיצה אחת.

## מה התוסף עושה

**עריכה** — רצועת כלים מלאה: גופנים וגדלים, מודגש/נטוי/קו תחתי, צבע וסימון, יישור והזחה, רווח שורות, רשימות ממוספרות ורשימות נקודות, שש רמות כותרת, מברשת עיצוב וניקוי עיצוב. יש גם חלונית ניווט לפי הכותרות שבמסמך, הערות בפתקיות בארבעה צבעים, והוספת תמונות עם ציפה לימין או לשמאל.

**חיבור לספרייה** — "ייבוא מהקורא" מכניס למסמך את הקטע שפתוח כרגע בקורא של אוצריא, יחד עם המקור שלו. התוסף גם מוסיף פריט לתפריט ההקשר של הקורא, כך שאפשר לשלוח קטע נבחר ישירות אל המסמך. חיפוש בספרייה ופתיחת ספר נעשים מתוך העורך עצמו.

**בדיקת איות תורנית** — מילון של מונחי תורה, ראשי תיבות וצורות כתיב מקובלות, כדי שמילים כמו רש"י או אאמו"ר לא יסומנו כשגיאה.

**מאקרו** — אפשר להקליט רצף פעולות עריכה ולהפעיל אותו שוב בקיצור מקשים.

**ייבוא וייצוא** — פתיחת קובץ Word קיים לעריכה, ייצוא חזרה ל‑docx, ייצוא לפורמט TXT של אוצריא כדי להוסיף את הכתוב כספר בספרייה, והדפסה.

**שמירה** — המסמכים נשמרים אוטומטית באחסון של התוסף, כשתיים וחצי שניות אחרי שמפסיקים להקליד. אפשר להחזיק כמה מסמכים פתוחים בלשוניות, ויש ארכיון למסמכים ישנים.

## התקנה

הדרך הפשוטה היא דרך חנות התוספים של אוצריא, ושם גם העדכונים מגיעים אוטומטית. להתקנה ידנית מורידים את קובץ ה‑`.otzplugin` מעמוד [Releases](../../releases), ובאוצריא נכנסים להגדרות ← ניהול תוספים ← התקנה מקובץ. נדרשת גרסה 0.9.92 ומעלה. אחרי ההתקנה מופיעה לשונית "וורד לאוצריא" בסרגל הכלים.

## פרסום גרסה חדשה

אחרי שמסיימים תיקון או שיפור ודוחפים אותו ל‑main, מפרסמים בדחיפת תג:

```
git tag v1.3.6
git push origin v1.3.6
```

מכאן הכל אוטומטי. הוורקפלואו `.github/workflows/release.yml` מסנכרן את מספר הגרסה ב‑`manifest.json` למספר שבתג, בונה את קובץ ה‑`.otzplugin`, בודק שהחבילה תקינה, יוצר Release בגיטהאב, ומעדכן את התוסף בחנות ב‑otzaria.org. משם המשתמשים מקבלים את העדכון תוך דקות ספורות. אין צורך לערוך את מספר הגרסה ביד — התג הוא מקור האמת.

חשוב שמספר הגרסה יהיה גבוה מזו שבחנות; החנות דוחה עדכון עם מספר גרסה שכבר קיים.

הבנייה מסתמכת על שלושה סודות המוגדרים בהגדרות המאגר (Settings ← Secrets and variables ← Actions): `OTZARIA_USER`, `OTZARIA_PASSWORD` ו‑`OTZARIA_PLUGIN_ID`. בלעדיהם שלב הפרסום לחנות מדולג, וה‑Release עדיין נוצר כך שאפשר להתקין מהקובץ.

לבנייה מקומית בלי לפרסם מריצים `build.ps1` ומקבלים `otzaria-word-editor.otzplugin` בשורש.

## מבנה המאגר

תיקיית `src` מכילה את קבצי המקור: `index.html` הוא הממשק, ותחת `js` נמצאים `app.js` (הלוגיקה הראשית), `export.js` (ייצוא ל‑docx ול‑TXT), `docs.js` (ניהול מסמכים ושמירה), `dictionary.js` (מילון האיות), `utils.js` ו‑`globals.js`. הקבצים `mammoth.min.js` ו‑`jszip.min.js` הם ספריות חיצוניות לקריאה וכתיבה של קובצי Word. קובץ ה‑`.otzplugin` שבשורש הוא אותם קבצים ארוזים, מוכן להתקנה.
